# App Source Structure

This directory is organized to match the app architecture for the React Native client.

- app: app shell and navigation entry points
- screens: feature screens grouped by domain
- components: reusable UI, forms, PDF, and feedback components
- features: feature modules with hooks and logic
- lib: shared client/server helpers and adapters
- store: state management stores
- theme: design tokens and theme configuration
- utils: generic helper utilities
- types: shared TypeScript types
- mocks: local mock data and API fixtures
